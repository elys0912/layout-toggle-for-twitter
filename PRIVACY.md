# Privacy Policy / プライバシーポリシー

Layout Toggle for Twitter — version 0.1.0

## English

- This add-on does not collect, transmit, sell, or share any data. It makes no network requests.
- It stores the following only in your browser, using `browser.storage.local`:
  - which items you chose to show or hide, and the layout options;
  - the names, link paths and icon shapes of the menu items and sidebar blocks it found on x.com, so the settings page can list them;
  - the time the add-on last ran on x.com, so the settings page can tell whether it is running.
- The stored data never leaves your browser. Removing the add-on deletes it.
- The add-on runs only on `https://x.com/*`.

## 日本語

- この拡張は、データを集めない・送らない・売らない・共有しない。通信は一切しない。
- 次のものだけを、`browser.storage.local` でブラウザの中に保存する。
  - どの項目を表示・非表示にしたかと、レイアウトの設定
  - x.com で見つけたメニューの項目と右サイドバーのブロックの名前・リンク先のパス・アイコンの形（設定画面に一覧を出すため）
  - x.com で最後に動いた時刻（設定画面で、動いているかを判断するため）
- 保存したものはブラウザの外へ出ない。拡張を削除すると消える。
- 動くのは `https://x.com/*` だけ。
